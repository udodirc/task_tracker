# 🧩 Task Tracker API

Task Tracker — это RESTful API на Laravel для управления задачами с авторизацией, WebSocket-уведомлениями и интеграцией с Telegram.

---

## 🎯 Цель

Разработать API на Laravel — Task Tracker — с возможностью:

- управления задачами,
- обновлений в реальном времени (WebSocket),
- авторизации пользователей,
- отправки уведомлений в Telegram.

---

## 📋 Основные возможности

### ✅ CRUD для задач

Пользователь может **создавать, просматривать, редактировать и удалять** задачи.

#### Структура задачи:
- `title` — название задачи *(string)*
- `description` — описание *(text)*
- `status` — статус *(enum: `new`, `in_progress`, `done`)*
- `assigned_user_id` — пользователь, на кого назначена *(nullable, foreign key)*
- `created_by_user_id` — автор задачи *(foreign key)*

---

### 🔐 Авторизация

- Регистрация и логин пользователя.
- Только авторизованные пользователи могут работать с задачами.
- Пользователь видит только свои задачи:
    - где он автор (`created_by_user_id`)
    - или назначен (`assigned_user_id`)

---

### 📡 WebSocket (реальное время)

- При изменении статуса задачи, все пользователи, которые имеют доступ к задаче, получают обновление в реальном времени.

---

### 🤖 Telegram-уведомления

- При создании новой задачи бот отправляет сообщение в Telegram.
- Сообщение содержит:
    - Название задачи
    - Кто создал задачу
    - На кого она назначена
    - Статус задачи

---

### 🐳 Docker

Проект запускается с использованием Docker.

Минимальные сервисы:
- PHP (Laravel)
- MySQL/PostgreSQL

---

## 🚀 Запуск проекта

1. Клонировать репозиторий:

   ```bash
   git clone git@github.com:udodirc/task_tracker.git
   cd task-tracker

2. Запустить Docker:

    ```bash
    cp .env.example .env
    docker compose up -d --build

3. Выполнить миграции и сиды:

    ```bash
    docker compose exec app php artisan migrate --seed
   
4. Сгенерировать ключ приложения:

    ```bash
    docker compose exec app php artisan key:generate
